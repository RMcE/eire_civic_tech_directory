We created HousePrice.ie to solve some of the shortcomings of the existing open data, and to aggregate the Property Price Register data with other sources to provide a more complete picture of the market.

As the website grew we added more features, such as:

-   A house price valuation tool which uses similarly sold properties in the same area to estimate the value of a property
-   A 'Nearby' feature which asks for permission to use your device's location to show you recently sold properties near your current location
-   A user account system which allows you to save properties, comment on them, and come back once they sell to see how accurate your valuation was.
